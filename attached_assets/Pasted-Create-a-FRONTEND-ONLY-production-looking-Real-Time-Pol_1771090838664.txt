Backend contracts (frontend uses these; backend separate):
REST:
- POST /api/polls
  req { question: string; options: string[] }
  res { pollId: string; shareUrl: string }
- GET /api/polls/:pollId
  res {
    pollId: string;
    question: string;
    options: { id: string; text: string }[];
    results: { optionId: string; votes: number }[];
    totalVotes: number;
    userStatus?: { hasVoted: boolean; votedOptionId?: string };
    shareUrl?: string;
  }
- POST /api/polls/:pollId/vote
  req { optionId: string }
  res same as GET OR { ok: true }

Socket.IO:
- client emits "poll:join" { pollId }
- server emits "poll:state" { pollId; results; totalVotes }
- server emits "poll:error" { message }

Fairness / anti-abuse client support (best-effort):
- localStorage stable clientId generated once (uuid-like)
- send X-Client-Id header on all REST calls
- localStorage voted marker: voted:<pollId> = optionId
- show UI lock if local marker exists, but reconcile with server userStatus (server wins)
